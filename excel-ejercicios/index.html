Excel: formatos, porcentajes y funciones

Formatos de celda, formato condicional, porcentajes y funciones básicas, aplicados al análisis de costos y presupuestos. Cada tema trae un ejercicio práctico con el resultado que tenés que obtener.

Es la continuación de la guía ilustrada de Excel. Sirve para Excel 365 (escritorio y online) y versiones 2016 o posteriores. Los cinco ejercicios se hacen en un mismo libro.

1Tipos de formato de celda

El formato de una celda define cómo Excel interpreta y muestra los datos, y eso afecta los cálculos. Por defecto todas las celdas están en formato General. Elegir el formato correcto es el primer paso antes de hacer cualquier operación.

FormatoQué haceEjemplo de uso
TextoGuarda caracteres sin valor matemático. Se alinea a la izquierda.Códigos de materiales, RUT, números de factura.
NúmeroValores para calcular. Permite controlar los decimales.Cantidades, rendimientos, stock.
Moneda / ContabilidadAgrega el símbolo $; en Contabilidad queda alineado a la izquierda.Costos, subtotales, precios unitarios.
FechaMuestra como fecha un número interno (por ejemplo, 23/06/2026).Plazos de entrega, cronogramas.
PersonalizadoAplica una máscara de visualización propia.Mantener ceros iniciales en códigos (máscara 00000).

Cómo cambiar el formato:

  1. Seleccioná las celdas.
  2. Andá a la pestaña Inicio.
  3. Buscá el grupo Número.
  4. Abrí el desplegable que dice General y elegí el formato.

2Formato condicional

El formato condicional cambia solo el color de una celda cuando se cumple una regla. Es ideal para detectar a simple vista un gasto que se pasó del límite.

  1. Seleccioná el rango que querés controlar.
  2. En Inicio, grupo Estilos, abrí Formato condicional.
  3. Elegí Reglas para resaltar celdas → Es mayor que…
  4. Escribí el valor límite y elegí el estilo Relleno rojo claro con texto rojo oscuro.
  5. Tocá Aceptar.

También sirve para marcar fechas vencidas con Reglas para resaltar celdas → Una fecha que ocurre…

4Porcentajes: IVA y precio final

Excel guarda los porcentajes como decimales: 22 % es 0,22. Para sumarle el IVA a un precio en un solo paso se usa =B16*(1+C16).

El 1+ representa el 100 % del costo original. Así, Excel calcula al mismo tiempo el costo base (B16 × 1) y el impuesto (B16 × 0,22). En la práctica multiplica por 1,22: $ 45.000 × 1,22 = $ 54.900.

5Funciones estadísticas

Estas funciones trabajan con un rango de celdas, que se escribe con dos puntos: B20:B23 significa «desde B20 hasta B23».

FunciónQué devuelveSintaxis
PROMEDIOEl promedio de los valores.=PROMEDIO(rango)
MAXEl valor más alto.=MAX(rango)
MINEl valor más bajo.=MIN(rango)
CONTARCuántas celdas tienen números.=CONTAR(rango)
CONTARACuántas celdas no están vacías (números o texto).=CONTARA(rango)

CONTAR sirve para saber cuántos materiales tienen precio cargado; CONTARA, para saber cuántos proveedores hay en la lista aunque alguno todavía no tenga precio.
